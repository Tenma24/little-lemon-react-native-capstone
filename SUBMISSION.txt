Description:
A React Native and Expo restaurant app with validated onboarding, a searchable menu with selectable categories, stack navigation, and a persistent editable profile. Logout clears saved profile data. The repository contains all project files, bundled illustrations, a JPG wireframe, editable SVG, screenshots, tests, and setup instructions.
